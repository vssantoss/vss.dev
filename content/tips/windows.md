# Windows

[HEIF / HEVC Video Extensions](ms-windows-store://pdp/?ProductId=9n4wgh0z6vhq), [2](https://apps.microsoft.com/store/detail/heif-image-extensions/9PMMSR1CGPWG)<br>
This link opens the Microsoft Store with the free codec provided by your device manufacturer.

[KioWare](https://www.kioware.com/)<br>
Kiosk solution for Windows. I tried the Windows Pro + Kiosk but the website that I have to use needs authentication and it is not possible to have the credentials saved. If you are looking for a Kiosk solution maybe you want to check this link too: [Secure Ubuntu Kiosk](https://ubuntu.com/tutorials/secure-ubuntu-kiosk)

[OBS Studio - Open Broadcast Software](https://obsproject.com)<br>
If you need a software to record your screen, OBS is the BEST solution.

[Open Hardware Monitor](https://openhardwaremonitor.org/)<br>
Core temp, fan speed and voltages in a free software gadget.

**Printer/Printing Problems**<br>
To uninstall unused printer drivers: `printui.exe /s`

**Screen Control**<br>
[f.lux](https://justgetflux.com/) makes the color of your computer's display adapt to the time of day, warm at night and like sunlight during the day.<br>
[PangoBright](https://www.pangobright.com/) is a free "screen dimmer" Windows utility for setting the brightness of your main screen as well as external monitors. It is also very small (the EXE is around 100K bytes), and is easy on your processor. It has one job, and one job only: to dim your screen(s).
