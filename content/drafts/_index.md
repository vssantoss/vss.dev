# Drafts

Personal scratch space. Everything under this section has `draft = true`
inherited from here, so it is never rendered to the live site, never listed,
and never added to feeds or the sitemap.

It still lives in the public repo (this is built in public), so treat it as
"visible source, unpublished page" — not as secret.

To preview drafts locally: `zola serve --drafts`.
